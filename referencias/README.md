# Referencias bibliográficas

- `Referencias_v6.md`: bibliografía legible del artículo, con 24 entradas.
- `Fuentes_bibliograficas_Word.xml`: fuentes de Word registradas también dentro del documento v6.
- `referencias_verificadas.json`: metadatos, identificadores y notas de contraste conservados de la revisión v6.

Las fuentes corresponden a las citas del manuscrito. No constituyen la lista completa de estudios del mapeo; para esta última, consulte `datos/extraccion/estudios_incluidos.csv`.

El Word conserva campos de cita vinculados y resultados formateados. La actualización automática de esos campos está bloqueada para preservar la presentación; no hay protección global del documento. Si se cambian metadatos bibliográficos, deben desbloquearse y revisarse las citas antes de volver a guardar el artículo.

Los marcadores `[@identificador]` de la fuente Markdown hacen referencia a las claves del archivo JSON. El repositorio reproduce resultados y figuras, pero no incluye un conversor de esos marcadores a Word.
